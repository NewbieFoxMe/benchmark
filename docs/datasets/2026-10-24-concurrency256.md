# 2026-10-24 双机并发评测

[对比数据](../../public/data/results.json) · [聚合证据](../../public/data/evidence/2026-10-24-concurrency-plot-data.json)

## 测试条件

- 模型：DeepSeek-V4.1-Flash-1017，权重版本 `1bae0e1088993b9b82de08f59de5be5a34e42170`。
- 硬件：两台实验主机，每台 4 张 RTX PRO 6000 Blackwell Server Edition 96 GB，共 8 张 GPU。
- 负载：每请求 1,028 个原生输入 token，最多输出 128 token；C1、C8、C16、C32、C64、C128、C256。
- 客户端：官方 vLLM benchmark client，经实验网关访问服务。每档独立预热，随后运行两批测量；每个引擎共 1,024 个测量请求。原生 token 计数、缓存命中与请求 trace 已核对。
- 比较范围：三组服务的总请求容量均为 256。结果反映各自并行、显存和 Graph 配置下的端到端系统表现。

## 指标映射

| 页面字段 | 聚合证据字段 | 口径 |
| --- | --- | --- |
| `outputTps` | `output_tokens_per_second_mean` | 两批输出吞吐的算术平均，token/s |
| `ttftSeconds` | `ttft_mean_ms / 1000` | 客户端平均首 Token 延迟，秒 |
| `requestDecodeTps` | `request_decode_tokens_per_second` | 逐请求计算首 Token 后输出速率，再求算术平均，token/s |
| `e2eSeconds` | `e2e_mean_ms / 1000` | 客户端平均端到端时间，秒 |

`measuredAt` 为该引擎、并发档位两批测量中较晚的完成时间。页面保留聚合证据中的全部有效精度，展示时再格式化。
